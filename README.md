# beest-avs47b-reader
LabVIEW controlling, reading, recording, and interpreting software for the AVS-47B for the Colorado School of Mines BeEST project.
This software is the fourth version (V4) of the general software for the project "BeEST Temperature Logger." V4 of the BeEST Temperature Logger is specifically referred to in-project as BASVR. When a subVI is labeled BASVR, that means it's specifically designed to handle the in-project needs, and is less generalized to data reading and graphing itself, as I intended for some of the software to be generalizeable to some tasks completely independent of the AVS-47B.

A few bugs and intended additions to the software are listed as a note in the bottom left of the back pannel. Most subVIs should be fairly well commented and legible, but I'm still learning. The software should be very flexible for changes and probing, and somewhat optimized (and at least is compared to V3).

The relevant subVIs, a few example logs, and our calibration sheet for a few resistors are included in the overall file, as well as some alias junk that I'm not confident is actually necessary.

Good luck!
